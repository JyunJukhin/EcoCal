# EcoCal 个人理财持仓记录工具 — 开发计划

## 1. 项目概述

一个离线运行的**持仓价值跟踪工具**，帮助用户记录自己持有的各类金融产品（股票、基金、债券、存款、理财等），随时记录其当前价值，由工具自动计算持有期间的实际收益、收益率与年化收益率，并以多币种口径统计全部资产总值、辅以可视化图表，辅助用户掌控资产状态、做出继续持有/卖出的决策。

**使用场景**：
1. 买入某产品时添加记录：产品名称、分类、币种、买入本金（成本）、买入数量/份额、开始持有日期。
2. 持有过程中，用户随时**添加价值记录**：记录该产品在某一日期的市值。
3. 工具结合买入成本与最新价值，自动计算**持有天数、累计收益、收益率、年化收益率**（单利/复利）。
4. 多币种资产按用户维护的汇率换算为**基准币种**，统计全部资产总值，用图表直观呈现结构。

**核心原则**：
- 所有数据（含汇率）由用户自主添加和修改，工具**不做任何联网查询**。
- 数据保存在浏览器本地（localStorage），关闭后重开仍显示上次记录。
- 纯静态网页，双击即用，零第三方依赖。

## 2. 功能需求

### 2.1 产品（持仓）管理 — 信息全面、分类清晰
- **添加产品**，字段尽可能完整：
  - 名称、类别（见 2.2 分类体系）、币种（见 2.3）。
  - 本金（买入总成本）**和** 买入数量/份额（两者可选其一填写，均填时自动校验成本 ≈ 单价 × 数量）。
  - 开始持有日期、备注。
- 编辑 / 删除产品（删除需二次确认，并级联删除其下全部价值记录）。
- 列表支持**按类别 / 币种筛选**、按市值 / 收益率等排序。

### 2.2 分类体系（多类金融产品）
- **大类（category）**：股票 | 基金 | 债券 | 存款 | 银行理财 | 保险 | 其他。
- **小类（subCategory）**，按大类细化，例如：
  - 股票：A 股 / 港股 / 美股 / 其他市场；
  - 基金：货币型 / 债券型 / 混合型 / 指数型 / 股票型 / QDII；
  - 债券：国债 / 企业债 / 可转债 / 其他；
  - 存款：活期 / 定期 / 大额存单；
  - 银行理财：固收类 / 权益类 / 混合类。
- 分类用于**统计与可视化**（按类别汇总资产占比、盈亏）。

### 2.3 多币种支持
- 每个产品独立设置**币种**：CNY / USD / HKD / EUR / GBP / JPY 等常见币种，并支持自定义币种代码。
- **汇率管理（设置面板）**：用户选择一个**基准币种**（默认 CNY），并手动维护"1 目标币种 = X 基准币种"的汇率。
  - 汇率仅供统计换算，**不联网获取**，界面明确提示"汇率需用户自行更新"。
  - 汇率保存在本地，可随时修改，修改后全部统计即时重算。
- 单产品指标优先用**本币**展示；跨产品汇总一律换算为**基准币种**。

### 2.4 价值快照记录
- 为产品**添加价值记录**：记录日期 + 当时市值（可与产品同币种）+ 备注。
- 支持追加多条记录，形成**持有时间线**；支持编辑 / 删除单条记录并自动重算。

### 2.5 自动计算指标（每个产品）
- **持有天数**：开始持有日期 → 最新记录日期 / 今天。
- **最新价值、累计收益 = 最新价值 − 本金**（本币口径）。
- **收益率 = 累计收益 / 本金**。
- **年化收益率（核心）**：
  - 单利口径（默认）：`年化 = 收益率 × 365 / 持有天数`；
  - 复利口径（参考）：`年化 = (最新价值 / 本金)^(365/持有天数) − 1`；
  - 持有 < 30 天时标注"持有时间过短，年化仅供参考"。
- 涨跌配色：收益为正红色、为负绿色（国内红涨绿跌）。

### 2.6 全部资产总价值统计（多币种）
- 汇总（全部按基准币种换算）：**总成本、总市值、总累计收益、整体收益率、整体年化**。
- 分币种小计（各币种资产的总市值与占比）。
- 盈亏产品计数、盈利/亏损金额汇总。
- 说明：换算口径下，收益同时包含**价格变动收益与汇率变动影响**，界面给出提示，避免误解。

### 2.7 可视化（原生 SVG，零依赖）
- **资产结构环图**：按类别（股票/基金/债券…）展示总市值占比；支持切换按币种口径。
- **市值排行条形图**：各产品市值的横向条形排行，亏损产品可高亮。
- **单产品走势折线图**：该产品价值记录的时间序列曲线。
- 图表跟随数据实时刷新，支持页面色调（浅色为主）。

### 2.8 数据持久化与备份
- localStorage 自动保存；首启空状态引导。
- JSON 导出 / 导入完整备份（含产品、价值记录、汇率设置）。
- 提供"清空所有数据"入口（需二次确认，恢复出厂）。

### 2.9 非目标（明确不做）
- 不做联网查询 / 行情获取 / 汇率获取 / 净值同步。
- 不做多用户、云同步、账户体系、实时交易。

## 3. 技术方案

| 项目 | 选型 | 说明 |
| --- | --- | --- |
| 页面结构 | HTML5 语义化 | 单页面应用 |
| 样式 | 原生 CSS3 | 变量驱动主题，苹果风格 |
| 逻辑 | 原生 JavaScript (ES6+) | 不使用框架 |
| 可视化 | 原生 SVG 手写图表 | 环图 / 条形图 / 折线图，零图表库 |
| 数据存储 | `localStorage` | JSON 序列化 |
| 依赖 | **零第三方依赖** | 遵循项目惯例 |

> 技术理由：纯本地工具、无联网，原生实现无构建、无依赖风险；三种图表用 SVG 手写工作量可控，且完全可控样式以贴合苹果风格。

## 4. 数据模型设计

### 4.1 产品（Asset）

```json
{
  "id": "asset_唯一标识",
  "name": "产品名称",
  "category": "股票 | 基金 | 债券 | 存款 | 银行理财 | 保险 | 其他",
  "subCategory": "如：A股 / 混合型 / 国债 …",
  "currency": "CNY | USD | HKD | EUR | GBP | JPY | 自定义代码",
  "principal": 10000.00,        // 本金（买入总成本，本币）
  "quantity": 1000,             // 买入数量/份额（可选）
  "startDate": "2024-11-01",    // 开始持有日期
  "note": "备注（可选）",
  "createdAt": 1735689600000,
  "updatedAt": 1735689600000
}
```

### 4.2 价值记录（Valuation）

```json
{
  "id": "valuation_唯一标识",
  "assetId": "asset_xxx",       // 关联产品 id
  "date": "2025-01-05",         // 记录日期
  "value": 10250.50,            // 当时市值（本币）
  "note": "可选备注（如：分红到账）",
  "createdAt": 1735689600000
}
```

### 4.3 设置（Settings / 汇率表）

```json
{
  "baseCurrency": "CNY",                       // 基准（统计）币种
  "rates": { "USD": 7.25, "HKD": 0.93, … }     // 1 币种 = X 基准币种，用户手动维护
}
```

### 4.4 计算规则
- 单产品：`最新价值` = 最后一条价值记录（无记录时视为本金）；`收益 = 最新价值 − 本金`；`收益率 = 收益 / 本金`；`持有天数 = min(最新记录日期, 今天) − 开始日期`；年化按 2.5 公式。
- 多币种换算：任意金额 × 该币种对基准币种的汇率；汇率缺失时按 1:1 并提示"该币种汇率未设置"。
- 汇总：各产品换算后的成本 / 市值 / 收益求和；整体收益率 = 总收益 / 总成本；整体年化 = 整体收益率 × 365 / 平均加权持有天数（简化口径，界面注明）。

## 5. UI/UX 设计（苹果风格）

### 5.1 视觉基调
- 大量留白，居中窄栏（最大宽度约 1080px）；背景 `#f5f5f7`，白色大圆角卡片（12–18px）、细边框 + 极浅投影。
- 字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro SC", "PingFang SC", "Helvetica Neue", sans-serif`。
- 强调色 Apple 蓝 `#0071e3`；涨跌色红 `#d70015` / 绿 `#1d9e49`（国内习惯）。
- 数字等宽对齐（`font-feature-settings: "tnum"`），金额带币种符号。

### 5.2 页面结构
```
┌───────────────────────────────────────────────┐
│ 顶部导航：EcoCal + 「添加产品」+「汇率设置」按钮 │
├───────────────────────────────────────────────┤
│ 汇总区（4 个大数字卡片，基准币种）               │
│   总成本 · 总市值 · 累计收益 · 整体年化         │
│   （附：分币种小计行）                          │
├───────────────────────────────────────────────┤
│ 图表区（2 张卡片）                              │
│   资产结构环图（按类别）  市值排行条形图          │
├───────────────────────────────────────────────┤
│ 产品列表（卡片，每张 = 一个持仓）                │
│   ├─ 名称 + 大类/小类标签 + 币种 + 持有天数      │
│   ├─ 成本 / 最新市值 / 收益(±) / 收益率(±)      │
│   ├─ 年化收益率（醒目）                        │
│   ├─ 操作：＋记价值 · 展开时间线 · 编辑 · 删除   │
│   └─ 展开区：价值记录时间线 + 走势折线图         │
│  筛选：按类别 / 币种筛选，按市值/收益率排序       │
│  空状态：友好引导 + 「添加第一个产品」            │
├───────────────────────────────────────────────┤
│ 模态框：添加/编辑产品 · 添加/编辑价值记录        │
│ 设置面板：基准币种选择 + 汇率编辑表              │
└───────────────────────────────────────────────┘
```

### 5.3 交互细节
- 表单即时校验：金额正数、日期合法且不晚于今天、币种必填、汇率 > 0；保存按钮仅在通过时可用。
- 任何增删改（含汇率）后：产品卡片、汇总、图表**同步刷新**。
- 删除产品 / 删除价值记录 / 清空数据均有二次确认。
- 图表在数据不足时（< 2 条价值记录）显示友好占位提示。
- 响应式：桌面与移动端均可用，图表自适应宽度。

### 5.4 可选增强（后续迭代）
- 深色模式、追加本金（多次买入合并成本与平均成本）。
- 份额 × 单价快速换算市值。
- 更多维度的图表（如按币种占比环图切换）。

## 6. 开发步骤（里程碑）

1. **M1 — 骨架搭建**：页面结构（导航、汇总区、图表区、产品列表、模态框、设置面板、时间线展开区）。
2. **M2 — 样式实现**：苹果风格主题变量、卡片、按钮、表单、弹层、图表容器、涨跌配色。
3. **M3 — 数据层**：localStorage 封装，Asset / Valuation / Settings（基准币种 + 汇率表）三类数据。
4. **M4 — 产品管理**：添加 / 编辑 / 删除产品；类别与币种字段；筛选与排序；表单校验；删除确认与级联清理。
5. **M5 — 价值记录与计算引擎**：价值记录增删改；单产品指标（持有天数、收益、收益率、单利/复利年化）；多币种换算与**全部资产汇总统计**（总成本/总市值/总收益/整体年化、分币种小计）。
6. **M6 — 时间线与走势图**：价值记录时间线渲染 + 单产品 SVG 折线走势图。
7. **M7 — 汇总图表**：资产结构环图（按类别）+ 市值排行条形图，随数据实时刷新。
8. **M8 — 汇率设置面板**：基准币种切换、汇率编辑、缺失汇率提示。
9. **M9 — 收尾打磨**：空状态、持有过短提示、导出/导入备份、清空数据、移动端适配、控制台无报错。

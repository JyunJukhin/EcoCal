# EcoCal 增量计划 · 股票分批买卖 + 行情联网

## 1. 背景与目标

当前工具按"一笔买入成本 + 市值快照"记账，适用于基金/理财类一次性投入。股票的真实场景是**多次买入（分批建仓）、部分卖出（减仓），不会全买全卖**；同时用户希望**联网获取当前股价与近期走势**（放弃"完全不联网"约束，但联网仅限行情查询，数据仍在本地）。

目标：
1. 支持股票（及可选类别）**多次买入 / 部分卖出**，自动计算持仓数量、平均成本、浮动盈亏、已实现盈亏；
2. **联网获取现价与近期走势**，行情失败时可手动回退；
3. 现有数据无缝升级，不丢、不破坏已有记录。

## 2. 功能需求

### 2.1 分批买卖（交易记录模式，**所有类别可选开启**）
- 每个产品在「编辑/新增」时**自主选择记账模式**：
  - **价值快照模式**（默认）：维持现行为——本金 + 价值记录时间线 + 市值走势（适合不频繁买卖的基金/理财/存款）；
  - **交易记录模式**：启用多笔买入/卖出（适合股票、定投基金、可转债等）。模式可随时切换；切换时旧数据按 §2.5 迁移。
- 交易记录模式下，每次操作记一笔 **Trade**：
  - **买入**：日期、数量、成交单价、手续费（可选）、备注 → 持仓数量增加、持仓成本增加；
  - **卖出**：日期、数量、成交单价、手续费（可选）、备注 → 持仓数量减少、产生**已实现盈亏**（卖出数量必须 ≤ 当前持仓，超额校验）；
  - 支持编辑、删除交易（删除后持仓与盈亏自动重算）；交易记录按日期排序形成**交易时间线**。
- 可同时存在多笔买卖（分批建仓、部分止盈、补仓摊薄、清仓后再买入等）。

### 2.2 持仓与盈亏计算（口径）
| 指标 | 公式（按**加权平均成本**口径） |
| --- | --- |
| 持仓数量 | Σ买入数量 − Σ卖出数量 |
| 持仓成本 | 剩余持仓的摊薄成本：每次买入 成本 += 数量×价 + 买入手续费；每次卖出 成本 −= 卖出数量×当前平均成本 |
| 平均成本价 | 持仓成本 ÷ 持仓数量 |
| 当前市值 | 持仓数量 × 最新股价（行情获取，可手动覆盖） |
| 浮动盈亏 | 当前市值 − 持仓成本（本币） |
| 已实现盈亏 | Σ(每笔卖出金额 − 卖出数量×当时平均成本)，卖出手续费从卖出金额中扣除 |
| 总盈亏 | 浮动盈亏 + 已实现盈亏 |
| 年化（近似） | 浮动盈亏 ÷ 持仓成本 × 365 ÷ 加权持有天数（口径见「帮助」，注明为近似值） |

- 不允许卖出超过持仓数量；卖出后平均成本自动摊薄。
- **允许卖超到 0 后再买入**（交易历史连续，成本重算正确）。

### 2.3 行情联网（现价 + 近期走势）
- 用户为股票填写**代码**（如 `sh600519` / `sz000001` / `hk00700` / `usAAPL`，腾讯行情代码格式，A股/港股/美股均可）；
- **当前股价**：每只股票卡片提供「刷新行情」按钮；可选"打开页面时自动刷新一次"（受开关与频率约束）；
- **近期走势**：展开区显示**日K折线图**（默认最近 60 个交易日，复权），复用现有 SVG 折线组件；
- 行情结果**缓存到本地**（带获取时间），联网失败时显示"行情获取失败 + 上次更新时间"，用户仍可**手动录入股价**（回退为现有价值记录机制）保证功能可用；
- 行情仅用于展示与计算，**不做交易、不做提醒推送**；接口为第三方免费服务，不保证实时与准确，帮助页说明。

### 2.4 界面变化
- **产品表单**：新增「记账模式」（价值快照 / 交易记录）；新增「行情代码」（任意类别可填，`sh600519`/`sz000001`/`hk00700`/`usAAPL`），初始持仓作为**首笔买入**（替代原"本金/数量"直填；原字段兼容并可迁移）；
- **交易记录模式卡片**：新增 持仓数量、平均成本价、现价、市值、浮动盈亏、已实现盈亏、总盈亏；操作按钮改为 「＋买入」「−卖出」「刷新行情」「交易记录/走势 /编辑 /删除」；
- **价值快照模式卡片**：维持现有布局不变，仅增加（若填了代码）现价与行情刷新入口；
- **展开区（交易模式）**：交易记录时间线（买卖明细 + 逐笔已实现盈亏）+ 股价日K走势；价值快照模式维持现有"价值记录时间线 + 市值走势"；
- **汇总区**：总市值、**总盈亏（浮动 + 已实现拆分显示）**、整体年化（口径更新），两种模式统一按基准币种换算；
- 行情设置并入「汇率设置」面板或独立「行情设置」（自动刷新开关、刷新频率说明）。

### 2.5 向后兼容与数据迁移
- 读取旧数据时：若产品**首次切换为交易记录模式且无交易记录**，自动用原有 `principal`（本金）+ `quantity`（数量）生成**一条买入交易**完成迁移，用户无感知；
- 价值快照模式的产品行为完全不变；
- 存储结构扩展（Asset 增加记账模式/symbol/行情缓存字段，新增 trades 表），读取层做字段缺省填充，旧备份文件可继续导入。

### 2.6 非目标（不做）
- 不做自动盯盘、价格提醒、真实下单；
- 不做分红除权/送转的自动处理（手续费与分红可在备注记录）；
- 不做多账户/券商导入。

## 3. 数据模型设计

### 3.1 交易记录（Trade，记账模式产品）
```json
{
  "id": "trade_xxx",
  "assetId": "asset_xxx",
  "type": "buy | sell",
  "date": "2026-01-05",
  "quantity": 100,        // 数量（股/份）
  "price": 12.50,          // 成交单价（本币）
  "fee": 5.0,              // 手续费（本币，可 0）
  "note": "分批建仓",
  "createdAt": 1735689600000
}
```

### 3.2 产品（Asset）扩展字段（记账模式 + 行情，通用）
```json
{
  "...原字段...",
  "enableTrades": false,   // 记账模式：false=价值快照 / true=交易记录
  "symbol": "sh600519",    // 行情代码（可选，任意类别可填）
  "priceSource": "auto | manual",  // 现价来源
  "lastPrice": 1450.00,    // 最近一次获取/录入的股价
  "lastQuoteAt": 1735689600000,    // 最后行情时间
}
```

### 3.3 行情缓存（Settings 扩展）
```json
{
  "autoQuote": true,               // 打开页面自动刷新行情开关
  "quotes": { "sh600519": { "price": 1450.0, "time": 1735689600000 } },
  "klineCache": { "sh600519": { "days": [...], "time": 1735689600000 } }
}
```

## 4. 计算规则（交易引擎，纯函数，可单测）

- `meanCost`：持仓成本 ÷ 持仓数量。
- **买入**：`cost += qty*price + fee`；`qty += qty`。
- **卖出**：`realized += qty*price - qty*meanCost - fee`；`cost -= qty*meanCost`；`qty -= qty`（校验 qty ≥ 0）。
- **浮动盈亏** = `qty*lastPrice - cost`。
- 交易按日期排序依次应用（同日交易按录入顺序），删除/编辑任意一笔后**全量重算**，保证一致性。
- 行情缺失时 `lastPrice = null`，市值与浮动盈亏显示 "--"，提示手动录入。
- 多币种：市值/成本按产品币种计算，汇总时按汇率换算为基准币种（已实现盈亏为历史已发生现金，按当前汇率近似换算，界面注明）。

## 5. 行情接口方案（免费、浏览器可直连）

| 用途 | 接口 | 说明 |
| --- | --- | --- |
| 实时/最新价 | 腾讯行情 `https://qt.gtimg.cn/q=sh600519,...` | 支持 sh/sz/hk/us（**A股 + 港股 + 美股**），返回文本；跨域可用 |
| 日K走势 | 腾讯K线 `https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh600519,day,,,60,qfq` | JSON，前复权，60 日 |

- 容错：接口失败 → 依次尝试备用源（新浪/腾讯备用端点），仍失败则使用缓存并提示；
- 频率约束：自动刷新每只股票不超过 N 分钟一次（默认 10 分钟），避免频繁请求第三方接口；
- 接口为公开免费服务，若失效可在帮助中说明并降级为手动录入。

## 8. 测试与验收标准

- [ ] 交易记录模式（任意类别，如股票）：多次买入（不同价格）→ 数量、平均成本、持仓成本计算正确（手工核对）。
- [ ] 部分卖出 → 持仓减少、已实现盈亏正确；卖出数量超过持仓被拒绝。
- [ ] 卖出至 0 后再买入，历史与成本正确。
- [ ] 编辑/删除任意一笔交易，全量重算后指标一致。
- [ ] 旧版数据（无交易记录）首次切换为交易记录模式时自动迁移为一笔买入，指标一致。

# EcoCal · 个人资产持仓记录工具

一个离线运行的个人理财持仓记录工具：记录你买入的各类金融产品（股票、基金、债券、存款等），随时记下当前市值，工具自动计算**持有天数、累计收益、收益率、年化收益率**，支持**多币种换算汇总**与**图表可视化**，帮助你掌控持仓状态、判断是否继续持有。

- **纯静态、零依赖**：原生 HTML + CSS + JavaScript，无任何第三方库，无需构建。
- **不联网**：不查询任何理财产品行情；仅汇率统计可自愿联网获取（免费公开接口），也可手动维护。
- **数据本地保存**：数据存于浏览器 localStorage，可导出 / 导入 JSON 备份。
- **可安装为 PWA**：托管后手机"添加到主屏幕"，全屏启动、离线可用。

## 功能特性

- **分类体系**：股票 / 基金 / 债券 / 存款 / 银行理财 / 保险 / 其他，含细分小类。
- **记账模式（产品级可选）**：「价值快照」（本金 + 定期市值）或「交易记录」（多次买入/部分卖出，自动算加权平均成本、浮动/已实现盈亏、总盈亏），旧数据切换模式自动迁移为买入记录。
- **行情联网（可选）**：填写行情代码（`sh600519` / `sz000001` / `hk00700` / `usAAPL`）即可获取现价与近 60 交易日走势（腾讯公开免费接口，A股/港股/美股）；接口不可用时手动录入现价。
- **全面字段**：名称、类别、币种、本金（成本）、数量/份额、开始持有日期、备注，及三个增强字段——**最低持有天数**（自动显示"可卖/不可卖·还需 X 天"）、**风险等级 R1–R5**、**T+n 到账**。
- **价值时间线**：随时记录"日期 + 市值"，形成持有历史与走势折线图。
- **自动计算**：持有天数、累计收益、收益率、年化（单利默认 + 复利参考）。
- **多币种**：每产品独立币种，汇率手动维护或联网获取（可切换基准币种，自动按比例折算）。
- **总资产统计**：总成本 / 总市值 / 累计收益 / 整体年化（按基准币种）+ 分币种小计。
- **可视化**：资产结构环图（按类别）、市值排行条形图、单产品走势折线图（原生 SVG，零图表库）。
- **手机友好**：导出支持"下载 / 复制到剪贴板"，导入支持"选择文件 / 粘贴 JSON"。

## 快速开始

| 方式 | 操作 |
| --- | --- |
| 本地直接使用 | 浏览器双击打开 `index.html`（数据存浏览器 localStorage） |
| 局域网/手机试用手感 | `node tools/serve.mjs`，手机同 WiFi 访问 `http://<电脑IP>:8123` |
| 安装为 PWA | 部署到静态托管（见下），手机首次联网访问后"添加到主屏幕" |

## 数据与隐私

- 所有数据保存在**当前浏览器**的 localStorage 中，不写入任何源码文件、不发送到任何服务器。
- 汇率接口为第三方免费公开服务（Open Exchange Rates / Frankfurter），仅用于换算统计，**不构成投资建议**。
- **敏感提醒**：`ecocal-backup-*.json` 为个人数据备份，已被 `.gitignore` 排除，**不要把备份文件上传到公开仓库/托管目录**。
- 换浏览器 / 换设备：用「导出(下载或复制) → 导入(文件或粘贴)」迁移。

## 目录结构

```
index.html          页面结构（业务骨架）
css/style.css       样式（苹果风格）
js/app.js           全部逻辑（数据层/计算引擎/SVG 图表/汇率联网/帮助）
manifest.json       PWA 应用清单
sw.js               Service Worker（离线缓存 App Shell）
icons/              PWA 图标（192/512）
docs/               计划文档、部署指南、预览图
tests/              回归测试（node tests/test-calc.mjs）
tools/              本地静态服务器、图标生成脚本
```

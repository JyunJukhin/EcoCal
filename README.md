# EcoCal · 个人资产持仓记录工具

一个离线运行的个人理财持仓记录工具：记录你买入的各类金融产品（股票、基金、债券、存款等），随时记下当前市值，工具自动计算**持有天数、累计收益、收益率、年化收益率**，支持**多币种换算汇总**与**图表可视化**，帮助你掌控持仓状态、判断是否继续持有。

- **纯静态、零依赖**：原生 HTML + CSS + JavaScript，无任何第三方库，无需构建。
- **联网可选**：股票行情与汇率均可自愿联网获取（免费公开接口），也可完全手动维护、离线使用。
- **数据本地保存**：数据存于浏览器 localStorage，可导出 / 导入 JSON 备份。
- **可安装为 PWA**：托管后手机"添加到主屏幕"，全屏启动、离线可用。

## 功能特性

- **分类体系**：股票 / 基金 / 债券 / 存款 / 银行理财 / 保险 / 外币 / 其他，含细分小类。
- **统一交易记录（v6）**：所有产品一律通过逐笔「买入 / 卖出」记账（原「价值快照」模式已合并删除，旧数据自动迁移为首笔买入 + 折算现价），自动计算加权平均成本、浮动 / 已实现盈亏、总盈亏、年化。
- **添加产品只填基本信息（v6）**：名称、大类小类、币种、风险等级、T+n、备注；股票额外填**代码**（自动识别市场/币种/名称，进监察表），外币额外选**外币币种**（以人民币买卖，按汇率计算收益）。
- **两种录入方式（v6）**：每笔买卖可选「**份数 × 单价**」（金额自动算，股票默认）或「**总金额**」（份额自动折算，基金等默认）。
- **非股票按金额记账（v6）**：基金/存款/外币等卡片以「持仓总金额」为主导指标；「✎ 市值」直接修改**当前持仓总金额**（系统折算单位价值）。
- **批次最低持有天数（v6）**：非股票产品的**每笔买入**可单独设置最低持有天数（如基金持有 7 天免赎回费），未到期批次显示「锁定」，可卖/部分可卖/不可卖徽章自动判定。
- **股票监察表（v5）**：添加股票只需填代码即可加入自选监察，随时「＋ 买入 / − 卖出」逐笔录入（买卖统一填单股价格）。
- **行情联网（可选）**：输入股票代码（A股 `600519` / `000001`、港股 `00700`、美股 `KO` / `AAPL`）即可获取现价与近 60 交易日走势（腾讯公开免费接口）；接口不可用时手动录入现价/市值。
- **自动计算**：持有天数、累计投入、浮动 / 已实现 / 总盈亏、收益率、年化（单利近似）。
- **多币种**：每产品独立币种；外币产品以人民币结算；汇率手动维护或联网获取（可切换基准币种，自动按比例折算）。
- **总资产统计**：总市值 / 累计投入 / 总盈亏（浮动+已实现）/ 总收益率 / 整体年化（按基准币种）+ 分币种小计（附占比）。
- **可视化（v6.2 重设计）**：统计页为渐变 Hero 总资产大卡 + 指标磁贴 + 2 列卡片式图表——资产结构环图（按类别/币种/风险等级切换，圆心显示总市值）、市值排行（渐变条形图）、组合市值走势（渐变面积 + 市值 vs 净投入）、盈亏构成分解（全部原生 SVG，零图表库）。
- **图表交互筛选**：点击环图切片按类别/币种/风险等级筛选列表，点击条形图只看该产品（再点取消），并有「图表筛选状态条」一键清除。
- **手机友好**：导出支持"下载 / 复制到剪贴板"，导入支持"选择文件 / 粘贴 JSON"；演示数据移至帮助页按需载入，主页无数据时留白。
- **设置面板**：基准币种、汇率管理（联网/手动）、行情自动刷新、清空全部数据（二次确认）等集中管理；「清空数据」不再占用顶栏。
- **产品页资产速览条（v6.6）**：「产品」页顶部新增 4 项速览卡（总市值 / 累计投入 / 总盈亏 / 总收益率），口径与统计页一致，**随筛选联动**（筛选生效时标注「筛选后 N 项」），无持仓时自动隐藏。
- **统计页章节重排 + 锚点导航（v6.6）**：「组合走势」上移到核心仪表盘之后；新增吸顶章节胶囊导航（核心仪表盘 / 组合走势 / 配置与结构 / 集中度 / 持仓明细），点击平滑跳转、滚动时**以视口中线判定并高亮**当前章节，窄屏横向滑动不换行。
- **移动端顶栏收纳（v6.6）**：窄屏下 帮助/导入/导出/设置 收起为「⋯」溢出菜单（点击外部 / Esc / 选择菜单项自动关闭），顶栏只留「＋ 添加产品」；桌面端保持平铺。
- **盈亏构成圆环修复（v6.6）**：修复「只有一种盈亏（100% 整圆）时圆环不渲染」的问题（360° 弧拆成两段半圆弧）；圆环颜色改用主题变量（浮动蓝 / 已实现橙 / 盈红 / 亏绿，深色模式自动提亮，圆心文字暗色下不再不可见）；有持仓但盈亏全为 0 时显示明确占位说明。
- **设置面板全新排版（v6.6.2）**：备份区卡片化重排（WebDAV / Gitee / 备份提醒 / 数据管理 4 张卡），长介绍文字收进「详细说明」折叠；汇率设置行卡片化（圆角输入框 + 短后缀「1 X 兑 基准」）；所有勾选框统一为苹果风 switch 开关（深色模式勾选/未勾选清晰区分）。
- **弹窗交互优化（v6.6.2）**：设置等弹窗打开时锁定主页面滚动（底部下拉不再穿透带动页面）；设置内 4 个标签页吸顶切换；每次打开设置自动回到顶部；顶栏新增主题按钮「🌓」循环切换 跟随系统/浅色/深色（设置面板不再放外观项）。
- **云备份可靠性修复（v6.6.2）**：修复「自动备份报 failed to fetch、但手动立即备份成功」——页面卸载瞬间发起的上传请求被浏览器取消，错误被记为「上次失败」且成功补备后仍显示旧错误；现改为待备份标记持久化、回前台/下次打开统一补传，成功/失败都会同步更新状态并在页面顶部弹出 3 秒迷你提示条。

## 快速开始

| 方式 | 操作 |

## 数据与隐私

- 所有数据保存在**当前浏览器**的 localStorage 中，不写入任何源码文件、不发送到任何服务器。
- 汇率接口为第三方免费公开服务（Open Exchange Rates / Frankfurter），仅用于换算统计，**不构成投资建议**。
- **敏感提醒**：`ecocal-backup-*.json` 为个人数据备份，已被 `.gitignore` 排除，**不要把备份文件上传到公开仓库/托管目录**。
- 换浏览器 / 换设备：用「导出(下载或复制) → 导入(文件或粘贴)」迁移。
